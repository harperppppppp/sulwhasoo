# Reference suitability

- Verdict: `conditional-pass`.
- 단일 대상, 강한 정면 실루엣, 충분한 해상도, 노출된 주요 재질과 완전한 전면 copy 때문에 procedural Three.js 재구성에 적합하다.
- 한 장의 정면 사진만 있어 깊이/후면은 관찰할 수 없다. 사용자가 요구한 스크롤 hero 용도에서는 정면 대칭 추정을 허용하고, 숨은 면을 정확하다고 주장하지 않는다.
- 정확한 제조용 mesh나 photogrammetry가 아니라 실시간 브라우저용 code-only 근사 모델을 목표로 한다.
